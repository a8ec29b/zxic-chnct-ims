# 设备验证记录

项目面向中兴微（ZXIC）方案的 ARMv7、uClibc 设备，使用设备现有的 AT、网络和 SQLite 接口。下列结果只说明测试过的固件组合，不能代表全部设备。

- 已在多台设备上通过内部 AT 查询确认中国电信 SIM，并验证 IMS 注册。部分设备重启后可自动启动并重新注册。
- 已在一台设备上使用真实普通短信验证原厂收件箱和未读提示；长短信真实接收尚未验证。
- 一台原厂短信库为空的设备按照原厂表定义创建表后写入模拟短信，原厂界面正确显示内容、发件人和未读状态。
- 部分固件需要在已激活的 IMS 上下文上补充 IPv6 地址和指向 IMS 代理的路由。程序调用原厂 SLAAC 工具并按当前 IMS 上下文配置，不设置无线频段。
- 已验证压缩程序可保存在可写存储，启动时解压到 `/tmp`。安装脚本支持保留已有的可写启动脚本。
- SIM 就绪时序、设备断电和网络重连可能影响启动或注册；注册续期、长短信实机接收与长期稳定性仍需验证。

设备固件的可执行文件、运行库、SIM 数据、短信、网络报文和鉴权材料不包含在仓库中。
